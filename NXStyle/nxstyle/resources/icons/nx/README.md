# NXStyle original CAD icons

These editable SVGs are original artwork created for NXStyle and licensed under
the project's LGPL-2.1-or-later license. They reinterpret familiar CAD operations
using independent geometry; no Siemens artwork, screenshots, or extracted icon
assets were used. They do not claim pixel-identical fidelity to Siemens NX.

Every icon has a 32 by 32 viewBox and rounded 1.15-unit dark slate outlines.
Blue and slate faces describe solids, gold faces identify the edited feature,
red curves identify sketch geometry, and fine blue construction lines describe
references and constraints. Green appears only for the finish-sketch check.
Highlights remain restrained so the functional silhouette stays readable at
16, 24, and 32 pixels. All graphics are editable paths and basic SVG geometry,
with no text, external references, or font dependencies.

Palette: outline #354d63, blue #91bad4 / #5f8eaf / #3f7399,
feature gold #fff0b9 / #d5a448, sketch red #bc5054, reference blue #6b94b4.
