The Windows download is now one executable file instead of a zip. Nothing else changes from 0.1.0: each download is an official FreeCAD 1.1.4 release, unmodified, with NX-Style, its bundled add-ons (Strata, Katydid, SheetMetal, LCInterlocking, DFM Workbench, FreeCAD-Nxt) and the launcher. Nothing to install and nothing downloaded at start; your normal FreeCAD settings are never touched.

| Download | For |
|---|---|
| `NX-Style-0.1.1-windows-x86_64.exe` | Windows 10/11, Intel or AMD. Double-click it. |
| `NX-Style-0.1.1-windows-arm64.exe` | Windows 11 on Arm. FreeCAD 1.1.4 has no Arm build for Windows, so FreeCAD runs through Windows' x64 emulation. |
| `NX-Style-0.1.1-linux-x86_64.AppImage` | Linux, Intel or AMD. `chmod +x`, then run it. |
| `NX-Style-0.1.1-linux-aarch64.AppImage` | Linux on 64-bit Arm. |
| `NX-Style-0.1.1-macos-arm64.dmg` | Macs with Apple silicon: drag NX-Style to Applications. |
| `NX-Style-0.1.1-macos-x86_64.dmg` | Intel Macs. |
| `SHA256SUMS.txt` | Checksums of the files above. |

On Windows, the first start unpacks FreeCAD once (about 2.2 GB, with a progress window) into `%LOCALAPPDATA%\FreeCAD-NXStyle\runtime`; later starts go straight to FreeCAD.

Without a GPU driver that offers OpenGL 2 (virtual machines, remote desktops), the Windows and Linux downloads start FreeCAD on Mesa's software renderer by themselves.

Not signed by Apple or Microsoft yet: on macOS, allow the app once in System Settings > Privacy & Security > Open Anyway; on Windows, SmartScreen may ask you to confirm with "More info" > "Run anyway".

Installation details: https://foadsf.github.io/freecad-nxstyle/nxstyle/installation.html#bundle
