NX command to FreeCAD command

Each NX-Style button carries NX’s name and runs a real FreeCAD command. Hover a button to see the FreeCAD command and its key; the Command Finder searches both names.

Where a cell lists several FreeCAD commands (A or B), the first one that exists in your FreeCAD version is used, so one ribbon serves FreeCAD 1.0 and 1.1. Buttons marked when available are left off the ribbon when the command is not there: a newer FreeCAD’s command, or Strata’s when Strata is off.

These tables are generated from the ribbon files in NXStyle/nxstyle/resources/ribbons/.
