Keyboard shortcuts

The NX bindings follow Foadsf/NXtips (NX’s default keys with their NX command IDs), plus Ctrl+T (Move Object) and Ctrl+Q (Finish Sketch) from the NX textbooks.

Every key below is pressed by the self-test through Qt’s real shortcut system, and must reach its FreeCAD command with no other action holding the same key. Keys marked sketch edit work while a sketch is open for editing.

NXtips binds F4 to Touch Mode, while two textbooks give F4 as Repeat Command. NX-Style follows NXtips; Repeat Command is on the Quick Access Toolbar.
FreeCAD’s own shortcuts that do not clash with these keep working, even with FreeCAD’s menus and toolbars hidden. To keep FreeCAD’s keys instead of NX’s, set "nx_shortcuts": false in the settings.
