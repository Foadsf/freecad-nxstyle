Keyboard shortcuts

The NX-based bindings follow Foadsf/NXtips (NX’s default keys with their NX command IDs), plus Ctrl+T (Move Object) and Ctrl+Q (Finish Sketch) from the NX textbooks. The focus, Command Finder, named selection and keyboard pointer shortcuts below are NX-Style accessibility extensions. They are listed separately from the NX-based mappings and are not claimed as NX defaults.

Every key below is pressed by the self-test through Qt’s real shortcut system, and must reach its FreeCAD command with no other action holding the same key. The reference table is generated from the shortcut definitions. It describes the default assignments; command availability depends on the document, active workbench and installed add-ons. Keys marked sketch edit apply while a sketch is open for editing. See Testing for the distinction between shortcut dispatch checks, offscreen Qt interaction tests and tests in a running FreeCAD.

NXtips binds F4 to Touch Mode, while two textbooks give F4 as Repeat Command. NX-Style follows NXtips; Repeat Command is on the Quick Access Toolbar.
FreeCAD’s own shortcuts that do not clash with these keep working, even with FreeCAD’s menus and toolbars hidden. To keep FreeCAD’s command keys instead of the NX-based mappings, set "nx_shortcuts": false in the settings. That leaves the keyboard access keys below unassigned too; their commands stay on Tools › Keyboard Access and in the Command Finder.

The keyboard access keys are ones no FreeCAD command holds. F10 (FreeCAD’s macro debugger Step Over) and Ctrl+Space (BIM’s Toggle Subcomponents) were considered and left to FreeCAD. The self-test lists every FreeCAD binding an NX-Style key takes over and fails if an access key takes one.

Alt with a digit on the numeric keypad does not run these: Windows uses it to type characters (Alt+0177 is ±).

Use Tab / Shift+Tab to move between controls and Space or Enter to activate a focused button. On a ribbon or bar button, Down opens its menu when one is available; a split button’s Enter runs its current command. Ribbon menus use the normal arrow keys and Enter. Escape closes an open menu first; from the ribbon it returns to the previous interface area.

Ribbon command tooltips show the currently assigned shortcut, or say No direct shortcut assigned and give the Command Finder route. Menu command help also uses the current assignments. Resource Bar and Selection Bar controls give their focus shortcut, then the Tab and Space route. An icon can therefore be reached without giving its command a dedicated key; the guide does not assign a direct shortcut to every command.

Select objects, faces, edges and vertices

Ctrl+Shift+Space opens a modeless dialog, so an existing task collector stays active. The object list shows each visible, selectable model’s label and internal name. It supports valid B-rep shapes; hidden or non-selectable objects, null or invalid shapes, meshes, datums and shapeless containers are excluded, with the limitation explained in the dialog.

  1. Press Alt+F and type part of an object’s label or internal name.

  2. Press Alt+O to focus the object list and use the arrows to choose a model.

  3. Press Alt+T and choose Object, Face, Edge or Vertex.

  4. Press Alt+G to focus the geometry list. Rows show the topological name, such as Face2, plus face area and centre, edge length or vertex coordinates.

  5. Use the arrows to choose a row, Space to toggle it, and Ctrl / Shift with the list’s selection keys to select multiple rows.

  6. Press Enter, or activate Select, to apply the highlighted picks.

For large models the geometry list shows at most 200 rows per page, with Previous page and Next page buttons. Pending row selection belongs to the current object and page. Enable Add to current selection with Alt+A before selecting geometry across objects or pages; otherwise a successful selection replaces the earlier picks. Active command collectors always add to the current selection.

The dialog uses the active Selection Scope, NX-Style filter and command collector, and sends the request through FreeCAD’s native selection gate. A refused request reports its reason rather than claiming success. If the model changes, the document closes or an object is replaced, the request is rejected; use Refresh before choosing geometry again. The dialog rechecks geometry before selection so a cached Face2 is not silently applied to changed topology.

Browsing and Escape do not apply pending picks or alter geometry. Picks already applied with Select stay selected when the dialog closes. Selection itself does not create a feature, save the document or finish an active modeling task.

Typed tasks and graphics navigation

Start a command through Command Finder or the ribbon, then use Alt+2 to enter the Task Panel. Use Tab / Shift+Tab for fields and buttons, the dialog’s underlined mnemonics where available, and typed values for dimensions and coordinates. Tab follows the task form’s own order; past the last control it comes round to the first instead of leaving the panel (and Shift+Tab the other way round). Use the area shortcuts to leave it. Multiline editors and tables keep their native Tab behavior. The task’s own validation, selection requirements, OK / Apply and Cancel behavior still apply. For example, find Block, enter its dimensions in the task fields, and activate its OK button; use named geometry selection when a later feature asks for a face or edge.

With the graphics view focused and the keyboard pointer off, Alt+Arrow rotates the view. FreeCAD’s own view keys keep their meaning: the arrow keys pan, Page Up / Page Down zoom, Shift+Left / Shift+Right turn the view by 90°, and Ctrl+Arrow toggles the dock overlays. Text fields, trees, menus and task dialogs retain their own navigation keys.

Keyboard pointer

F12 displays a crosshair in the active graphics view. It sends the same viewport events used by the existing interaction tools, so it can reach picks and interactions that do not have a typed field or named-selection route.

While the pointer is active Action

Arrow keys

Move the crosshair by 10 screen pixels.

Shift+Arrow

Move by 1 pixel.

Ctrl+Arrow

Move by 30 pixels.

Enter

Left-click at the crosshair.

Ctrl+Enter

Start or end a left-button drag; move with the arrows between presses.

Space

Middle-click at the crosshair, using the current tool’s middle-button behavior, including accepting a task where MB2 means OK.

Menu or Shift+F10

Right-click at the crosshair.

F12 or Escape

Stop the pointer. A further Escape can cancel the active command.

The pointer is a screen-position tool: use typed values for exact coordinates and named selection for identifiable geometry. It does not add geometric snapping rules or replace a workbench’s own task behavior. In a sketch tool, FreeCAD gives an on-view dimension box the keyboard focus whenever the pointer moves, as it does for mouse moves. Digits then go into that box, and the pointer’s arrows and Enter still move and click: type a value, then press Enter to place the point with it. Turn the pointer off with F12 to use the boxes' own Enter and Tab. Keyboard access to native dialogs and add-on canvases also depends on their controls; these routes are not a claim that every FreeCAD or add-on workflow has been exercised without a mouse.

Hide and Show

Ctrl+B and Ctrl+Shift+K act on the selection, and work at once after you select something in the Part Navigator. With nothing selected, Ctrl+Shift+K opens a list of the hidden objects to show (user-interface.adoc#_show_and_hide). In a sketch, both keys act on the dimensions and constraints you select (Sketching).

Every key that acts on the selection (Hide, Show, Ctrl+I, Ctrl+D, Ctrl+J, Ctrl+T …​) works straight after a pick. FreeCAD enables its commands only a moment after the selection changes, so NX-Style checks the key’s command itself when the key is pressed.
