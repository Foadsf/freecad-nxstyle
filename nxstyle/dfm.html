Molded Part Validation (DFM)

Analysis › Molded Part Validation on the Modeling ribbon checks a part against the rules of a manufacturing process before it goes to the toolmaker, the printer or the machine shop. The checks come from the DFM Workbench (Ryan Kembrey, LGPL-2.1-or-later), which NX-Style bundles in vendor/FreeCAD-DFM-Workbench and the launcher loads. The bundled copy is a fork of its version 0.4.3 that adds a CNC milling process (CNC milling). Its commands exist from start-up, so they sit on the Modeling ribbon; there is no separate application to switch to. The add-on’s own command name is shown in each button’s tooltip (FreeCAD: DFM Analysis under Moldability Validation).

Before the first use

The add-on needs OCP (cadquery-ocp), which FreeCAD does not ship, and gmsh for its colour maps. Until they are installed the launcher prints DFM: off: it needs OCP and the group is not on the ribbon. Install them once:

python launch_nx.py --install-dfm-deps

This runs FreeCAD’s own Python (pip install --no-deps) and puts cadquery-ocp 7.8.1.1.post1, VTK 9.3.1 and gmsh 4.15.2 in FreeCAD-NXStyle/pydeps/py311, beside the NX profiles and outside the FreeCAD installation. cadquery-ocp 7.8.1 matches the OpenCASCADE 7.8.1 that FreeCAD 1.1 is built on. --no-deps keeps VTK from bringing in numpy 2 and matplotlib, which would shadow FreeCAD’s own copies. Of VTK only its DLLs are kept, which OCP links to: FreeCAD ships VTK 9.3.1’s Python package itself for Pre/Post (FEM), and a second copy on the path made switching to Pre/Post hang. The launcher then adds that folder to FreeCAD’s module path (-M) ahead of the add-on, and never downloads anything by itself.

The buttons

Button Add-on command Does

Moldability Validation

DFM Analysis

Checks the selected part (or the only body in the part) against every rule of a process and material, and lists the findings.

Check Wall Thickness

Thickness Analysis

Colours the part by wall thickness on a uniform mesh, with a legend.

Draft Analysis

Draft Analysis

Colours the part by draft angle to a pull direction on a uniform mesh.

Process Library

Process Library

Creates and edits processes, their rules and their materials' limits.

NX has the first three under the same names: Moldability Validation on the Molded Part Design tab, Check Wall Thickness under Molded Part Validation, and Draft Analysis in the Face Shape group of the Analysis tab. Process Library has no NX counterpart and keeps the add-on’s name. NX’s Check-Mate checkers are not mapped: the add-on has no checker framework of that kind.

Injection molding checks draft, wall thickness, undercuts and sharp corners, and the recognised features: bosses, ribs, holes, living hinges, snap fits and molded text. The printing processes check overhangs, bridges, holes, pins, text, gaps and, for resin and powder, sealed hollows.

CNC milling

CNC Milling (3-axis) comes from the bundled fork. An end mill cuts walls parallel to its axis and leaves its own radius in every inside corner between them, so its Tool Corner Radius rule looks at the edges that run along the tool axis:

  • a sharp inside corner there is a corner of radius 0: no end mill cuts it;

  • a rounded inside corner or the end of a slot is a corner of its radius;

  • a whole hole is drilled or bored, not milled round a corner, and is left out.

A corner below At least (the radius of the smallest end mill the shop will use for those walls; 0.5 mm by default, 1 mm in stainless steel) is an error, one below Aim for (3 mm, a Ø6 end mill) a warning. Minimum Wall Thickness uses the Protolabs Network (Hubs) figures: 0.8 mm aimed for and 0.5 mm at least in metals, 1.5 and 1.0 mm in POM. Run the analysis once per setup, with that setup’s tool axis: corners along other axes are another setup’s.

How to run it

  1. Select the part (a Body, or a Part solid), then Analysis › Molded Part Validation › Moldability Validation.

  2. In the task panel, choose the process, then the material. Directions (pull, print, tool axis) start along +Z; click a face or an edge to change one.

  3. Run analysis. A progress panel shows each rule as it is measured, with an Abort button. The results panel then lists the findings by criticality and rule; click one to highlight its face or edge, and double-click to zoom to it. Rules with no finding are listed under Passed.

  4. Save keeps the results in the document; Close restores the part’s colours. The panel also exports CSV and compares runs (its History tab).

The add-on measures the heavier rules in worker processes, one per processor core but one (at most 12). Each worker loads its own FreeCAD, so a run with many cores uses several GB; ParallelWorkers in BaseApp/Preferences/Mod/DFM caps them. NX-Style’s self-test runs with 2.

Running it from a script

import time
from OCP.gp import gp_Dir
from freecad.DFM.app.analysis_runner import AnalysisRunner

deadline = time.monotonic() + 600          # give up after 10 minutes
results = AnalysisRunner().run_analysis(
    "CNC Milling (3-axis)", "Aluminium 6061", body.Shape,
    progress_cb=lambda done, total, name: print(f"{done}/{total} {name}"),
    check_abort=lambda: time.monotonic() > deadline,
    TOOL_AXIS=gp_Dir(0, 0, 1))
for r in results:
    print(r.rule_id.name, r.severity.name, r.overview, r.failing_geometry)

check_abort is asked before each face or edge, so the time limit holds within a second or so (measured on a 579-face engraved panel: stopped at 20.3 s for a 20 s limit). Name the inputs a process asks for as keyword arguments: PULL_DIRECTION, PRINT_ORIENTATION, TOOL_AXIS (each a gp_Dir), NOZZLE_DIAMETER, LAYER_HEIGHT (mm), and for injection molding SIDE_ACTIONS=[] and NOMINAL_WALL_THICKNESS={"mode": "auto"}. With launch_nx.py --run, --timeout bounds the whole run as well.

Switching it off

python launch_nx.py --no-dfm, or "dfm": "none" in nxstyle.json, starts without the add-on, and the Molded Part Validation group is not on the ribbon. A DFM Workbench already installed in the NX profile’s Mod folder (by the Addon Manager) is used instead of the bundled one, never both.

Limits

  • The checks are rule-of-thumb checks for a designer, not a mold-flow simulation.

  • Findings name faces and edges by number (Edge7). If the part changes after a saved analysis, the add-on warns when the document is opened again that those numbers may have moved.

  • Check Wall Thickness and Draft Analysis mesh the part with gmsh; a very fine mesh on a large part takes a while.

  • Tool Corner Radius looks at corners along one tool axis per run, for flat end mills: the radius between a wall and a pocket floor (a ball or bull-nose end mill) is not checked. A drilled hole that a slot cuts open is a partial cylinder, and is reported as a corner of its radius.

  • There is no turning process: a turned part’s checks (grooves, threads, internal corners against the insert’s nose radius) are not covered.
