About

Licence

FreeCAD NX-Style is free software under the LGPL-2.1-or-later, the same licence as FreeCAD. Strata and Katydid are separate projects under the same licence, included as git submodules. FreeCAD’s SheetMetal add-on (Shai Seger and contributors, LGPL-2.1) is included the same way, unmodified, for the Sheet Metal application. LCInterlocking (execuc and contributors, LGPL-2.1) is included for the Laser Cut application as a fork with two fixes for FreeCAD 1.1 (Qt 6), under the same licence. Katydid is not affiliated with Robert McNeel & Associates; Grasshopper is their trademark, named only to describe the style of tool.

Trademarks

Siemens, NX and Teamcenter are trademarks of Siemens. This project is not affiliated with or endorsed by Siemens, and uses no Siemens software, icons or documentation text. NX command names are used only to say which FreeCAD command does the same job.

Sources

  • NX key bindings: Foadsf/NXtips.

  • NX layout, commands and behaviour: the NX textbooks listed on Tutorials, checked against Siemens' and FreeCAD’s own sources where possible.

  • FreeCAD facts: FreeCAD 1.0.2 and 1.1.4, measured on Windows 11, and FreeCAD’s source code.

Contributing

Issues and pull requests are welcome on GitHub. Before a pull request, run the checks in Testing; for documentation changes see Writing these docs.
