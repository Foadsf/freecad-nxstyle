= NX command to FreeCAD command
:description: Every ribbon button, its NX name and the FreeCAD command it runs.

Each NX-Style button carries NX's name and runs a real FreeCAD command.
Hover a button to see the FreeCAD command and its key; the xref:user-interface.adoc#quick-access-toolbar-and-command-finder[Command Finder] searches both names.

Where a cell lists several FreeCAD commands (`A` or `B`), the first one that exists in your FreeCAD version is used, so one ribbon serves FreeCAD 1.0 and 1.1.
Buttons marked _when available_ are left off the ribbon when the command is not there: a newer FreeCAD's command, or Strata's when Strata is off.

These tables are generated from the ribbon files in `NXStyle/nxstyle/resources/ribbons/`.

== Modeling

include::partial$generated/ribbon-modeling.adoc[]

FreeCAD has no thread command for a shaft (PartDesign's Hole threads only holes).
NX-Style's *Thread* (`NXStyle_Thread`) builds a Detailed thread as a PartDesign *Subtractive Helix* of a thread profile sketch, and a Symbolic one as a feature that records the thread on the Body (xref:modeling.adoc#thread[Thread]).

NX's *Edit › Move Object* (kbd:[Ctrl+T] and the MB3 radial menu) is NX-Style's *Move Object* (`NXStyle_MoveObject`): it moves a Body's free features and the sketches attached to its origin (FreeCAD 1.1's PartDesign Boolean ignores a target Body's Placement), and sets the Placement of Part objects and links (an attached sketch's or datum's Attachment Offset) by a typed Distance, Angle or Point to Point motion, and makes copies as new Bodies, static Part features or links.
Its *Dynamic* motion is FreeCAD's *Transform* (`Std_TransformManip`), which had kbd:[Ctrl+T] before (xref:modeling.adoc#move-object[Move Object]).

== Sketch (contextual tab)

include::partial$generated/ribbon-sketch.adoc[]

*Studio Spline* is FreeCAD's B-spline group with *B-spline by interpolation* (`Sketcher_CreateBSplineByInterpolation`) as its default: NX's Type *Through Points*.
NX's *By Poles* is *B-spline by control points* (`Sketcher_CreateBSpline`) in the button's drop-down, or *From control points* in the tool's panel; the periodic kinds are NX's *Closed* (xref:sketching.adoc#studio-spline[Studio Spline]).
