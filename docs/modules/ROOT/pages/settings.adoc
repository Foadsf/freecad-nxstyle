= Settings
:description: Every NX-Style setting, its default and where to change it.

NX-Style reads its settings from `nxstyle.json` in the NX profile's `config` folder (xref:installation.adoc#profile[where the profile is]).
The file holds only what you change; everything else keeps its default, so new defaults still reach an existing profile.

At every start NX-Style writes `nxstyle.defaults.json` next to it: every setting with its default, for reference.

== Changing a setting

. Close NX-Style.
. Create `nxstyle.json` in the profile's `config` folder, or open it if it is there.
. Put in the settings to change, for example:
+
[source,json]
----
{
  "labels": "freecad",
  "background": "white",
  "mb3_hold_radial_menu_ms": 0
}
----
. Start NX-Style again.

A setting that holds several values (`colors`) can be changed one value at a time:

[source,json]
----
{ "colors": { "selection": "#E07000" } }
----

The settings in FreeCAD's own *Preferences* (File › Preferences) are separate and live in the same profile; they never touch your normal FreeCAD's.

| Keep FreeCAD's keyboard shortcuts | `"nx_shortcuts": false`

| Your normal FreeCAD's navigation and macros (xref:#import[below]) | `"import_preferences": ["navigation", "macros"]`

== Your normal FreeCAD's preferences

The NX profile starts with NX-Style's choices, not your normal FreeCAD's.
To bring some of yours across, name them in `nxstyle.json`:

[source,json]
----
{ "import_preferences": ["navigation", "macros"] }
----

At every start the launcher then copies them from your normal FreeCAD profile into the NX profile.
It only reads your normal profile and never writes to it.

[cols="1,4",options="header"]
|===
| Group | What comes across

| `navigation` | Navigation style, orbit style (Turntable, Free Turntable, Trackball...), rotation mode, zoom at cursor, wheel direction, zoom step, animations, rotation centre (File › Preferences › Display › Navigation).
| `view_cube` | Whether the view cube is shown, and how it looks.
| `macros` | The macro commands of *Tools › Customize › Macros*, which then get buttons on *Tools › Macros*, and your macro files, copied into the NX profile's own `data/Macro` folder (which becomes its macro folder if it had none of its own). Your macro folder itself is never used, so a macro recorded or edited in NX-Style stays in the NX profile. A command already in the NX profile, by its macro file, is not added twice, and a macro file already there is kept as it is.
| `all` | All of the above.
|===

`true` means `["navigation"]`.
For one start only, use `python launch_nx.py --import-preferences` (navigation) or `--import-preferences navigation,macros`.

With `navigation` imported, the graphics window behaves as in your normal FreeCAD, so NX-Style's own mouse handling (MB2 rotate, MB2 click = OK) is off.
What you set in `nxstyle.json` still decides: `"navigation": "nx"` keeps NX-Style's mouse handling, and the same holds for `zoom_at_cursor` and `invert_wheel_zoom`.
NX-Style's MB2 rotation then turns the view its own way, so your orbit style and rotation mode do not apply to it; the wheel is FreeCAD's, so your zoom step does.

The launcher looks for your normal profile where FreeCAD keeps it: `%APPDATA%\FreeCAD` on Windows, `~/.config/FreeCAD` on Linux, `~/Library/Application Support/FreeCAD` on macOS, in the `v1-1` subfolder that FreeCAD 1.1 makes for each version.
If you keep it elsewhere, give the folder that holds `user.cfg`, `Mod` and `Macro`: `"normal_profile": "D:/FreeCAD/profile"`.
Where `user.cfg` and the rest are in two folders, as on Linux, give both: `"normal_profile": {"config": "~/.config/FreeCAD/v1-1", "data": "~/.local/share/FreeCAD/v1-1"}`.
It writes what it copied to `nxstyle.imported.json` next to `nxstyle.json`; remove `import_preferences` and the file goes at the next start, while the copied FreeCAD preferences stay in the NX profile until you change them.

NOTE: Before 2026-10-13, NX-Style read `nxstyle.json` from the profile's root folder instead of `config`.
A file left there is still read when `config` has none.

== Ribbon layout

What you choose on the ribbon itself is kept in `nxstyle.ribbon.json`, next to `nxstyle.json`: for each application, tab and group whether it is *Keep Expanded* or *Always Collapsed* (right-click a group), and whether the ribbon is minimised.
NX-Style writes it as soon as you change something; you do not edit it by hand.
*Reset Ribbon Layout* on a group's right-click menu, or deleting the file, returns to the defaults.
See xref:user-interface.adoc#narrow-window[A narrow window].

== Starting over

`python launch_nx.py --reset-profile` deletes the NX profile, settings and FreeCAD preferences included; the next start makes a fresh one.
