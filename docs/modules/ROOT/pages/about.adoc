== Sources

* NX key bindings: {nxtips}[Foadsf/NXtips].
* NX layout, commands and behaviour: the NX textbooks listed on xref:tutorials/index.adoc[], checked against Siemens' and FreeCAD's own sources where possible.
* FreeCAD facts: FreeCAD 1.0.2 and 1.1.4, measured on Windows 11, and FreeCAD's source code.

== Contributing

Issues and pull requests are welcome on {repo}[GitHub].
Before a pull request, run the checks in xref:testing.adoc[]; for documentation changes see xref:writing-docs.adoc[].
