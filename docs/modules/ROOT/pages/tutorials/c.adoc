== In short

. The block by Extrude; four holes; Edge Blend on the corners.
. *Feature › Datum › Datum Plane* at an angle to a face, then one offset from it.
. Select the offset datum plane, click *Hole*: a sketch opens on the plane; place the centre, kbd:[Ctrl+Q], and the Hole dialog opens.

The angled upper block (C9) is skipped: its profile is in a figure only.

== What differs from NX

* FreeCAD's At Angle plane turns about the face's own axes in the attachment offset; NX lets you pick the hinge axis.
* Hole drills at circle centres in a sketch; NX places hole points directly.
